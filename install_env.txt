Voici un rappel rapide des commandes pour utiliser `venv` :

1. Créer un environnement virtuel :

Placez-vous dans le répertoire de votre projet et exécutez la commande suivante pour créer un environnement virtuel nommé `_env` :

python -m venv _env

2. Activer l'environnement virtuel :

Sous Windows, activez l'environnement avec la commande suivante :

.\_env\Scripts\Activate

sous linux:
source _env/bin/activate

Vous devriez voir le nom de l'environnement virtuel apparaître dans l'invite de commandes, indiquant que l'environnement est activé.

3. Installer des paquets dans cet environnement :

Une fois l'environnement activé, vous pouvez installer des paquets de manière isolée en utilisant `pip` :

pip install <nom_du_paquet>

4. Désactiver l'environnement virtuel :

Lorsque vous avez fini de travailler, vous pouvez désactiver l'environnement avec :

deactivate
